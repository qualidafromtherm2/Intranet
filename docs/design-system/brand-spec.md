# Thermo Design System — Flux Core

Sistema visual claro, industrial e compacto para sustentar aproximadamente 100 telas operacionais com comportamento consistente.

```css
:root {
  --bg: oklch(97.7% 0.004 250);
  --surface: oklch(100% 0 0);
  --fg: oklch(22% 0.045 252);
  --muted: oklch(47% 0.018 250);
  --border: oklch(90% 0.008 250);
  --accent: oklch(58% 0.23 24);
}
```

- Interface e títulos: `"Inter", "Segoe UI", sans-serif`.
- Códigos e números técnicos: `"IBM Plex Mono", Consolas, monospace`.
- Pesos permitidos: 400, 500 e 600.

Regras observadas:

1. Azul navy `#0B1D34` estrutura navegação, títulos e ações principais.
2. Vermelho `#E31837` aparece apenas na marca, alertas e pendências críticas.
3. Superfícies brancas e cinza claro `#E6E8EB` mantêm alta legibilidade.
4. Ícones são exclusivamente Lucide, lineares, com traço de 1,75 px.
5. A linguagem Flux Core comunica gestão, integração e controle com densidade operacional.
