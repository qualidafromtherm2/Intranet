Thermo · Flux Core

Design system operacional

Especificação de referência para as ~9 áreas do Thermo (Produtos, Estoque, Compras, Expedição, Produção, Qualidade, SAC, RH, Administração). Prioriza densidade de informação e leitura rápida sobre efeito visual — é uma ferramenta de operação diária, não uma superfície institucional. Onde a identidade da marca dá a régua (cores, símbolo), este documento formaliza como ela se comporta em tabela, formulário, kanban e estado de erro.

Tokens

Dois níveis: tokens de marca vêm fechados do manual e não são editáveis por produto; tokens de produto são derivados deles para resolver problemas que o manual não cobre — estado de sucesso/erro, fundo de aplicação, texto secundário.

Componentes

Altura padrão de controle: 36px. Todo componente interativo tem foco visível e nome acessível. Os três últimos desta lista (KPI crítico, card de kanban, orbit-stepper) não existem em bibliotecas genéricas — são assinatura do Thermo, derivados da lógica de fluxo/órbita do símbolo.

Botões

Vermelho sólido é reservado a "Excluir"/destrutivo. Ação principal positiva ("Salvar", "Nova solicitação") é sempre navy — o manual proíbe vermelho como cor dominante de interface; aqui ele fica só no ponto de maior risco da tela.

Acessibilidade

Critérios obrigatórios antes de qualquer componente entrar em produção — não é revisão opcional de polimento.

Contraste4,5:1 para texto normal, 3:1 para texto grande e ícones — o vermelho da marca sobre navy só é usado em elementos grandes, nunca em texto corrido pequeno (regra do próprio manual).
Foco visívelContorno de 3px em todo elemento interativo; ordem de tabulação segue a ordem visual, sem exceção para "componentes bonitos".
Alvo de toque40px no desktop, 44px em telas de toque — vale para ícone isolado, não só para botão com texto.
Validação de formulárioErro aparece junto ao campo, em texto, nunca só por borda vermelha — mensagem persistente até o campo ser corrigido.
